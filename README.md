# Manohar's portfolio

Static GitHub Pages portfolio for [ManoharUchiha](https://github.com/ManoharUchiha).

## Local preview

Run `python3 -m http.server 8000` in this directory, then open <http://localhost:8000>.

The site uses plain HTML and CSS. Project descriptions are drawn from the linked public repository READMEs; update `index.html` when adding or changing featured projects.
